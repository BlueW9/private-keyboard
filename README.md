# Privacy Keyboard

A minimal dark-theme Android keyboard.

- Arabic + English built in, globe key to switch
- Fully offline (no INTERNET permission)
- No clipboard, no suggestions, no history
- Number row, symbols pages
- License: GPL-3.0-or-later

## Build
Push a tag (`git tag v1.0.0 && git push --tags`) and GitHub Actions builds the APK and attaches it to the Release.
